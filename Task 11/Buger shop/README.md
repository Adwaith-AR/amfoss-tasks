# Burger Shop

Hey! Welcome to my Burger Shop project. I built this website as a solution for burger shop owners to handle online orders and boost their sales. 

On a personal note, this is also a practice project I put together to brush up on my frontend skills and get better at building web apps.

## Live Demo
Check out the live website here: [Burger Shop](https://buger-shop-six.vercel.app/)

## Features
- **Aesthetic UI:** A clean, theme-based design that makes use think it is ai :).
- **Customizable Burgers:** Let users build and customize their orders exactly how they want them.
- **Interactive Alerts:** Simple pop-ups and notifications to let users know what's happening.
- **Easy to use:** Straightforward ordering process for the customers.

## Tech Stack
I just know the basics so i kept it simple and solid using standard web technologies:
- HTML5
- CSS3
- JavaScript
